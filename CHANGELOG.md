# v0.3.0

**Added**

- CJ in the normal model selector.
- Third-person and freecam controls in the overlay.
- Persistent Photo Mode indicator during freecam.
- Stacked notifications for model selections and overlay changes.
- Launcher Logs tab for the current session.
- Custom save and shader-cache folders.

**Fixed / improved**

- Freecam turning during F7 + arrow model selection.
- Overlay navigation through disabled settings, with highlighting but no editing.
- Shader-cache startup and a diagnostic logging freeze.
- Removed broken Lucas Echo and spacesuit selections.
- Renamed first-party files and runtime identifiers to KZSF.
- Simplified launcher logs and removed em dashes.

**Known issues / planned**

- Pause and Collectibles menu rendering remains broken. The candidate fix was reverted after an FPS drop.
- CJ zipline and chapter compatibility need further verification.
